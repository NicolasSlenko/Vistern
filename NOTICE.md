# Third-party notices

## resumezip

Vistern's "paper" design system — the sheet-over-sky layout, the glass and
frame treatment, the button and segmented-control system, the small
monospace label style, and the three-column editor layout — is adapted from
**resumezip** by Ian Hoang.

- Source: https://github.com/ian-hoang/resumezip
- Licence: MIT
- Copyright (c) 2025 Ian Hoang

What was taken is the CSS idiom and the layout, rewritten for Vistern's
palette (green rather than blue), given a dark mode it did not have, and
re-pointed at Vistern's own data. No resumezip source file is vendored; the
files below are adaptations and each carries an attribution comment:

- `src/app/styles/zip-tokens.css`
- `src/app/styles/zip-glass.css`
- `src/app/styles/zip-sheet.css`
- `src/app/styles/zip-studio.css`
- `src/components/resume-studio/pills.ts`
- `src/components/resume-studio/use-thumb.ts`
- `src/components/resume-studio/fields.tsx`
- `src/components/resume-studio/mode-tabs.tsx`
- `src/components/resume-studio/section-nav.tsx`
- `src/components/resume-studio/section-form.tsx`
- `src/components/resume-studio/studio-shell.tsx`
- `src/components/resume-studio/preview-pane.tsx`
- `src/components/resume-studio/review-panel.tsx`
